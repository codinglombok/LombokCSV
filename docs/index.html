LombokCSV

CSV → HTML tables — parse, auto-detect types, aggregate, and format. Zero-dependency, RFC 4180.

Install

npm install lombokcsv

RFC 4180 parser

Handles quoting, escaping, custom delimiters.

Type detection

Auto-detects string, number, date, boolean.

HTML tables

Semantic, styleable table output.

Aggregation

GROUP BY with SUM, AVG, COUNT.

Auto delimiter

Detects comma / semicolon / tab automatically.

Large files

Streaming-friendly, memory efficient.

Quick start

import { CSV } from 'lombokcsv'

const csv = new CSV(csvString)
csv.parse().detectTypes()

const html = csv.toHTML({ header: 'bold', alternateRows: true })
const summary = csv.aggregate({ groupBy: 'Department', sum: ['Salary'] })
